# Changelog

## 0.1.0 - 09/2026
* Initial release of the Small Gallery Card for Home Assistant.
* Core image and video viewing via media paths (`media_source/local/`).
* Right-side thumbnail sidebar with automatic sorting (`asc` / `desc`).
* Single and batch file deletion support via `shell_command.del_gallery_file`.
* Manual refresh capability via header button.
* English as the default, and German on German-language systems.
